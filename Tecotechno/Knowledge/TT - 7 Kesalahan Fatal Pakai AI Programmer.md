## Ringkasan
7 cara pakai AI biar bukan cuma tukang suruh: Fase Mikir: (1) Define masalah dulu baru solusi, (2) AI sebagai partner brainstorming bukan generator ide instan, (3) Susun PRD (Product Requirement Document) ubah ide samar jadi spesifikasi konkret (anatomi PRD: context, problem, user stories, acceptance criteria, tech stack, constraints). Fase Eksekusi: (4) Review & setujui spek sebelum implementasi, (5) Kasih spek ke AI agent, kerjain bertahap, (6) Verifikasi hasil — JANGAN terima kode tanpa paham, (7) Error → usahakan benerin sendiri dulu, AI buat riset bukan auto-fix. Pola "asal prompt" ngerugiin jangka panjang: tidak paham, tidak belajar, tidak bisa debug.

## Poin Penting
- AI = partner berpikir, bukan fotokopi kode
- PRD = jembatan ide → implementasi (context, problem, user stories, acceptance criteria, tech stack, constraints)
- Verifikasi kode WAJIB: paham logika, trace flow, cek edge case
- Debug sendiri dulu → AI buat riset (cari tahu kenapa error, bukan minta fix langsung)
- Belajar dari proses > dapet kode instan

## Langkah / Cara Kerja
1. Mikir: "Apa masalahnya?" → tulis PRD → review dengan AI (brainstorm)
2. Finalisasi PRD → setujui spek
3. Eksekusi: bagi task kecil → kasih ke AI agent per task
4. Review output AI → paham logika → test manual
5. Error? Baca stack trace → coba fix sendiri → cari referensi → tanya AI "kenapa error ini?" bukan "fix ini"
