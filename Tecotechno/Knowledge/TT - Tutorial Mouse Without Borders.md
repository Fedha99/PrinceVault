## Ringkasan
Tutorial menggunakan Mouse Without Borders (bagian Microsoft PowerToys) untuk mengontrol hingga 4 PC Windows dengan 1 mouse & keyboard. Mencakup persiapan, instalasi PowerToys, generate Security Key, linking PC, atur posisi monitor virtual, tips optimasi (Wrap Mouse, Share Clipboard, LAN preferred), troubleshooting, dan keamanan.

## Poin Penting
- Gratis, resmi Microsoft, tidak butuh KVM Switch fisik
- Butuh Windows 10/11, jaringan lokal sama, PowerToys terinstall di semua PC
- Security Key untuk pairing; atur posisi monitor virtual biar kursor natural
- Fitur: Share Clipboard (copy-paste lintas PC), transfer file, Wrap Mouse
- Hanya Windows; butuh jaringan stabil (LAN preferred); firewall bisa blokir

## Langkah / Cara Kerja
1. Install PowerToys di semua PC (Microsoft Store/GitHub)
2. PC Utama: buka PowerToys → Mouse Without Borders → Enable → New Key
3. PC Kedua: buka PowerToys → Enable → masukkan Security Key + nama PC utama → Link
4. Status jadi "Connected" → atur posisi monitor virtual di pengaturan
5. Aktifkan Share Clipboard, Wrap Mouse; gunakan LAN untuk latensi terendah
