## Ringkasan
Panduan lengkap menggunakan Bitwarden (password manager open-source) dari membuat akun, install aplikasi/ekstensi, menambah password, auto-fill, sinkronisasi, sampai tips optimasi dan FAQ. Mencakup kelebihan/kekurangan, dampak keamanan, dan perkembangan Passkeys.

## Poin Penting
- Bitwarden: open-source, zero-knowledge, enkripsi AES-256, gratis unlimited device & sync
- Master Password minimal 14-16 karakter unik; wajib aktifkan 2FA
- Fitur: Password Generator, auto-fill (Ctrl+Shift+L), sinkronisasi lintas platform, Passkeys support
- Premium US$10/tahun untuk Vault Health Reports
- Risiko: lupa Master Password = data tak terpulihkan (zero-knowledge)

## Langkah / Cara Kerja
1. Buka bitwarden.com → Create Account → email + Master Password → Submit
2. Aktifkan 2FA di Account Settings
3. Install app/ekstensi di Windows/macOS/Linux/Android/iOS/Chrome/Edge/Firefox/Brave/Opera/Safari
4. Tambah item: klik ikon → Add Item → isi nama, username, password, URL → Save
5. Gunakan auto-fill: klik ikon → pilih akun atau Ctrl+Shift+L
6. Sinkronisasi otomatis antar perangkat
