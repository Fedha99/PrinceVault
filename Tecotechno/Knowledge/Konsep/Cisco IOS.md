## Definisi
Cisco IOS (Internetwork Operating System) OS proprietary Cisco untuk router/switch enterprise. Mode hierarki: User EXEC > Privileged EXEC > Global Config > Interface/Routing/Line Config. Stabilitas terbukti puluhan tahun, TAC 24/7, sertifikasi CCNA/CCCIE global standard.
