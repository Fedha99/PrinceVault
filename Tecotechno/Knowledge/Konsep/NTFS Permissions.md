## Definisi
NTFS Permissions = sistem hak akses Windows (ACL) untuk file/folder pada drive NTFS. Allow/Deny per user/group. Deny priority > Allow. JANGAN Deny Administrators/SYSTEM. Tidak enkripsi data → untuk data sensitif kombinasikan BitLocker. Butuh user terpisah per orang (bukan shared admin account).
