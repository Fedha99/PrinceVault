## Definisi
Wine (Wine Is Not an Emulator) = compatibility layer menjalankan aplikasi Windows di Linux (translate Windows API ke POSIX). Digunakan untuk The Dude Client (Windows-only) di GNS3 Linux. Butuh `winetricks` untuk dependency (dotnet, vcrun).
