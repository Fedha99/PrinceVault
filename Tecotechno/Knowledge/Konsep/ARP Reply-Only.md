## Definisi
ARP Reply-Only mode pada interface MikroTik: interface hanya merespons ARP request untuk IP-MAC yang sudah terdaftar di ARP table. Mencegah device dengan IP static liar (tidak terdaftar) komunikasi di jaringan. Butuh kombinasi DHCP Static Lease + Add ARP For Leases agar device legit otomatis terdaftar.
