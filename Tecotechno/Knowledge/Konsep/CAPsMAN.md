## Definisi
CAPsMAN (Controlled Access Point System Manager) adalah centralized wireless management MikroTik. Controller (CAPsMAN) menyediakan provisioning, datapath, security, channel config ke CAP Client (AP). Single point config untuk banyak AP, roaming seamless, VLAN per SSID.
