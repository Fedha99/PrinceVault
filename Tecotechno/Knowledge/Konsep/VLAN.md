## Definisi
VLAN (Virtual Local Area Network) memisahkan broadcast domain logis di infrastruktur fisik yang sama. VLAN ID (1-4094) tagging frame (802.1Q). Trunk port = tagged (bawa multiple VLAN), Access port = untagged (satu VLAN, PVID). Isolasi layer 2, butuh routing (Layer 3) untuk komunikasi antar VLAN.
