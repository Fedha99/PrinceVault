## Definisi
LLD (Low-Level Discovery) Zabbix = otomasi pembuatan item/trigger/graph untuk entitas dinamis (interface jaringan, disk, filesystem, CPU core). Template "MikroTik by SNMP" pakai LLD detect interface Ethernet/WLAN otomatis → bikin item per interface tanpa manual.
