## Definisi
Distance Vector = kelas protokol routing (RIP, IGRP) di mana router hanya tahu jarak (metric) ke tujuan via tetangga (vektor). Algoritma Bellman-Ford. Berbeda dengan Link State (OSPF, IS-IS) yang punya topologi penuh. Konvergensi lambat, rentan loop.
