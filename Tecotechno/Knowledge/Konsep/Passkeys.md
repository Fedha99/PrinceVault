## Definisi
Passkeys = credential passwordless berbasis WebAuthn/FIDO2 (public-key cryptography). Private key tersimpan di device/TPM, public key di server. Phishing-resistant (domain-bound), sync via iCloud Keychain / Google Password Manager / Bitwarden. Ganti password + 2FA untuk login modern.
