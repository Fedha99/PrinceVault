## Definisi
DHCP (Dynamic Host Configuration Protocol) otomatisasi pembagian IP address ke client. Komponen: IP Pool (range IP), DHCP Server (daemon), Network (subnet/gateway/DNS), Leases (IP-MAC binding). Static Lease = kunci IP ke MAC. ARP Reply-Only + Add ARP For Leases = anti IP conflict.
