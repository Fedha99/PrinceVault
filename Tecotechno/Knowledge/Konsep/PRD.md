## Definisi
PRD (Product Requirement Document) = dokumen spesifikasi yang mengubah ide samar jadi spesifikasi konkret untuk implementasi. Anatomi: Context, Problem, User Stories, Acceptance Criteria, Tech Stack, Constraints. Jembatan antara fase mikir (brainstorming) dan fase eksekusi (coding).
