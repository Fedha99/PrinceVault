## Definisi
Docker adalah platform containerization yang mengemas aplikasi + dependensi jadi image portabel. Container = instance image yang jalan (share kernel host, ringan vs VM). Komponen: Image (read-only template), Container (rw instance), Volume (persist storage), Dockerfile (build recipe), Docker Compose (multi-container orchestration).
