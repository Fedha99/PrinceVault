## Definisi
Zabbix adalah platform monitoring enterprise open-source untuk jaringan, server, aplikasi, log. Arsitektur: Server (polling/trapping), Agent (active/passive), Proxy, Web UI. Support SNMP untuk network device (MikroTik), IPMI, JMX, log monitoring, auto-discovery (LLD).
