## Definisi
OSI 7 Layers (Open Systems Interconnection) model konseptual ISO: L7 Application (HTTP/SMTP/DNS), L6 Presentation (SSL/TLS/JPEG), L5 Session (NetBIOS/RPC), L4 Transport (TCP/UDP), L3 Network (IP/Router), L2 Data Link (MAC/Switch), L1 Physical (Kabel/WiFi/Fiber). Enkapsulasi turun 7→1, dekapsulasi naik 1→7. TCP/IP = implementasi 4 layer.
