## Definisi
The Dude = network monitoring system bawaan MikroTik (GRATIS). Server di RouterOS (CHR/RouterBOARD), Client Windows (via Wine di Linux). Auto-discovery topologi, SNMP probe, ping probe, visual map real-time. Cocok NOC kecil/menengah.
