## Definisi
Winbox adalah aplikasi GUI resmi MikroTik untuk manajemen RouterOS berbasis Windows (bisa jalan di Linux via Wine). Mengakses router via MAC address (layer 2) atau IP address. Menyediakan interface visual untuk semua fitur RouterOS.
