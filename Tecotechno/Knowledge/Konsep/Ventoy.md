## Definisi
Ventoy = tool open-source bikin USB bootable multi-ISO (1x install → copy-paste file ISO berulang, no reflash). Support 1300+ OS, format exFAT/FAT32/NTFS/UDF/XFS/Ext2/3/4, Secure Boot native. CLI `Ventoy2Disk.sh` reliable di distro minimal.
