## Definisi
OSI 7 Layers = model edukasi detail (L7→L1). TCP/IP 4 Layers = implementasi nyata internet: Application (L7+L6+L5), Transport (L4), Internet (L3), Network Access (L2+L1). OSI breakdown detail gampang troubleshooting; TCP/IP dipakai produksi.
