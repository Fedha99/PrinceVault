## Definisi
Firewall RouterOS: Filter Rules (chain input/forward/output), NAT (srcnat/dstnat), Mangle (marking packet/connection/routing). Chain input = ke router sendiri, forward = lewat router, output = dari router. Address List untuk dynamic blocking (brute force). Connection tracking (conntrack) untuk stateful inspection.
