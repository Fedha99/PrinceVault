## Definisi
KVM (Kernel-based Virtual Machine) = modul kernel Linux yang mengubah Linux jadi hypervisor. Bekerja bareng QEMU untuk akselerasi hardware (VT-x/AMD-V). GNS3 Linux memanfaatkan KVM native untuk overhead virtualisasi minimal vs Windows (VirtualBox/VMware layer).
