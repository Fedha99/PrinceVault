## Definisi
Zero Trust = model keamanan "never trust, always verify". Tidak ada entitas (user/device/agent/service) yang otomatis dipercaya berdasarkan lokasi jaringan. Tiap request diverifikasi: identity, device health, permission, context. Diterapkan di ACP Protocol (agent-agent), Zabbix Agent Active (push log), MikroTik firewall (allowed address, address-list).
