## Ringkasan
Artikel mengulas sepuluh pilihan untuk membangun atau menjalankan agen AI: Hermes Agent, OpenClaw, OpenCode, Kimi K2.6, n8n, CrewAI, Flowise, Dify, LangChain/LangGraph, dan Botpress. Pilihannya mencakup alat CLI, framework kode, otomasi workflow, dan builder visual. Label gratis perlu dibaca hati-hati: biaya hosting, model, API, serta perubahan lisensi atau paket dapat tetap berlaku.

## Poin Penting
- Agen AI dapat menyusun beberapa langkah dan menggunakan tool untuk mencapai tujuan; chatbot biasa umumnya berhenti pada percakapan.
- n8n dan Dify cocok untuk otomasi visual; CrewAI dan LangChain/LangGraph untuk sistem yang lebih dapat dikustomisasi; Flowise dan Botpress menawarkan builder visual.
- Tool yang gratis tidak otomatis berarti inferensi model dan infrastruktur tanpa biaya. Self-hosting dapat mengurangi biaya API tetapi memerlukan sumber daya dan pemeliharaan.
- Mulai dari satu use case kecil, batasi hak akses, dan uji perilaku agen sebelum menghubungkannya ke sistem penting.

## Langkah / Cara Kerja
1. Definisikan satu tugas berisiko rendah dan kriteria berhasilnya.
2. Pilih platform menurut kebutuhan: visual, CLI, workflow, atau framework kode.
3. Tentukan model dan hitung biaya API atau hosting lokal.
4. Berikan akses tool seminimal mungkin dan uji dengan data yang tidak sensitif.
5. Tinjau hasil serta log sebelum memperluas otomasi.
