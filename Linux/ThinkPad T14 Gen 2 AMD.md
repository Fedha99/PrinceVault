# ThinkPad T14 Gen 2 AMD (Laptop Baru)

- **Status:** Sudah dipesan, **expected arrival awal September 2026**.
- **Tujuan:** Gantiin [[Spek HP Pavilion g4]] yang dibatasin GPU Intel HD 4000.

## Setup Day-1 yang Udah Direncanain
- Update BIOS ke **v1.17+**.
- Di UEFI: ubah **Sleep State → "Linux"** (biar sleep/wake behavior kompatibel).

HP Pavilion g4 lama rencana dialihfungsiin jadi **home server** — liat [[Home Server Planning]].
