# Spek HP Pavilion g4 (Sistem Utama Saat Ini)

- **OS:** Artix Linux x86_64, OpenRC init
- **Kernel:** 7.1.3-2-cachyos-bore
- **CPU:** Intel Core i7-3612QM (8 threads) @3.10GHz
- **GPU:** Intel HD Graphics 4000 (integrated, Ivy Bridge) @1.10GHz — **bottleneck utama**
- **RAM:** 11.57GB
- **Display:** 1366x768, 14", 60Hz
- **WM:** Hyprland 0.56.1 (Wayland)
- **Shell/Terminal:** bash + kitty
- **Tema:** Catppuccin (GTK2/3), Papirus-Dark icons, JetBrainsMono Nerd Font
- **Network:** local IP eth0 `192.168.23.254/24`

## Keterbatasan
GPU Intel HD 4000 ini yang bikin banyak keputusan desain harus disesuain — liat [[Constraint Intel HD 4000]].
