# Hyprland Config — Lua-based

- Config pake **native Lua API** Hyprland, bukan `.conf` hyprlang standar — misal `hl.config()`, `hl.bind()`, dll.

## Struktur Dotfiles (~14MB, Artix)
- `hypr/` — config Lua-based
- `hyprpaper.conf`
- `waybar/`
- `dunst/`
- `kitty/` — varian Catppuccin
- `scripts/`
- `themes/`
- `widgets/`

## Fitur Tambahan
- **Pywal-based dynamic color system** — dipasang buat theming otomatis.
