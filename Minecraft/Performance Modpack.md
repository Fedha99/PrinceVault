# Performance Modpack

## Forge Stack (200+ mods, dark fantasy)
- Baseline: **65 FPS** post-fix di Intel HD 4000.
- Mod performance yang kepake: liat kategori "Performance" di [[Daftar Mod Lengkap]] (Embeddium, ferritecore, starlight, dll).

## Fabric Performance Stack (tes terpisah)
Kombinasi: **Sodium, Lithium, Starlight, FerriteCore, Iris**, dll.
- Hasil: **~120 FPS** — jauh lebih ringan dibanding Forge stack.

## Insight
Trade-off jelas antara **mod count/fitur (Forge, 200+ mods)** vs **performance murni (Fabric stack)**. Constraint GPU jadi faktor penentu keputusan platform.
