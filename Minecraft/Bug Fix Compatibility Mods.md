# Bug Fix — Compatibility Mods

Masalah kompatibilitas yang muncul selama build [[Modpack Forge 1.20.1 Overview]].

## ✅ Resolved
- **rubidium-extra vs Embeddium** — incompatible (konflik sesama Sodium fork). **Solusi:** rubidium-extra dihapus total.
- **AzureLib NeoForge jar dipake di environment Forge** — nyebabin `NoClassDefFoundError`. **Solusi:** swap ke build `-forge-` yang benar (`azurelib-neo-1.20.1-3.1.12.jar` dikonfirmasi versi yang jalan).

## 🟡 Masih Flagged
- **GeckoLib/AzureLib version conflict** dengan **EpicFight** — belum resolved sepenuhnya.
- **Epic Fight vs T.O Magic** — compat warning.
